# Digital Letter Approval System

A Laravel-based web application designed to manage and approve resident letter requests within a municipal or councilor office.

## 🚀 Features

- Resident letter request submission
- Councilor approval & rejection system
- Digital signature support
- Upload stamp functionality
- Request tracking and status updates
- Admin and role-based access control

## 🛠️ Technologies Used

- PHP (Laravel Framework)
- MySQL Database
- Blade Templates
- JavaScript / AJAX
- Bootstrap (UI)

## 🔐 Roles

- **Resident** – submits letter requests  
- **Councilor/Admin** – approves or rejects requests
